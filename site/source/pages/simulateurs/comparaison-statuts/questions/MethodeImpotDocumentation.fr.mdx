# Méthode de calcul de l’impôt sur le revenu

## Barème standard

Le calcul « officiel » de l’impôt, celui sur lequel l’administration fiscale
se base pour calculer votre taux d’imposition.

## Taux personnalisé

Vous pouvez utiliser directement le taux personnalisé communiqué par
l’administration fiscale pour calculer votre impôt. Pour le connaître,
vous pouvez-vous rendre sur votre [espace fiscal
personnel](https://impots.gouv.fr).
